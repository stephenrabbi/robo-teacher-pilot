# Curated topic videos

`rounding-nearest-ten.mp4` is a 41-second English worked example created for Robo-Teacher on 3 November 2026. It explains rounding positive whole numbers to the nearest ten, using 47 → 50 and a correctly spaced number line from 40 to 50.

The narration was generated through Robo-Teacher's existing Google Cloud speech route using a synthetic build session. The original diagrams were drawn from numeric coordinates and encoded with FFmpeg (H.264/AAC MP4 and VP9/Opus WebM, 1280 × 720). No learner information, third-party video or student photographs are included. The VTT file provides English captions, and the text file contains the complete transcript.

The player resolves a fixed catalog ID to local assets. It starts paused and saves playback position without a media URL. Restored positions are validated and bounded by the actual video duration. Question return and reload recovery stay paused. The existing Exit control returns to the exact original explanation. Other topics retain existing simulations and narrated/text examples; this release adds one video, not a full subject-video library.
