# Presenter interaction prototype

Open `presenter.html` locally to review explanation, visual and compact video layouts, plus question-break/return behaviour. This page has no backend calls, microphone, speech, video playback or learner storage. It is not linked from the production classroom.

The existing speaking portrait remains the teacher during speech, listening, preparation and pause. The classroom uses the presenting pose while an idle visual, example or understanding check is shown. Browser screenshots confirmed a clean result against the purple panel. A still pose is not continuous hand animation. Herbert's existing welcome-page photograph is authorised as a possible second avatar; this prototype does not replace either identity.

Generated with the built-in image-generation tool from the existing teacher reference. Refinement prompt: “Preserve the teacher exactly as shown, same face, outfit, pose, framing and hands. Remove all background pixels and all glow/halo around her hair, shoulders, arms and hand. Output a clean crisp photographic cutout on truly transparent background, with fully opaque person and transparent outside silhouette. No shadow, no ambient glow, no blurred colors, no dark backdrop. Do not alter face or pose.” The raw image preview appeared to have a halo; composited browser screenshots showed that the cutout renders cleanly on the purple panel.

The classroom pose follows existing lesson and audio state; it returns to the portrait for speech, listening, pause and preparation. Browser tests verify pose changes and exact lesson return at four widths. Continuous articulated hand animation remains future work. The standalone preview has simulated controls only.
