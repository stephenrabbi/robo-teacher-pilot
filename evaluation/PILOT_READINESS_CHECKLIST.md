# Robo-Teacher Pilot Readiness Checklist

Do not start learner activity until every mandatory item is complete.

## Cohort and schedule

- [ ] Pilot start date confirmed
- [ ] Pilot end date confirmed
- [ ] School or schools confirmed
- [ ] Class level or levels confirmed
- [ ] Invited learner count confirmed
- [ ] Inclusion and withdrawal procedure confirmed
- [ ] Teacher/pilot lead named privately

## Consent and privacy

- [ ] Consent or permission evidence retained privately
- [ ] Random Pilot IDs assigned
- [ ] Identity roster stored separately from evaluation data
- [ ] Public repository and issue tracker contain no learner identifiers
- [ ] Data-retention and deletion responsibility confirmed

## Assessment

- [ ] Teacher reviewed Form A against the taught curriculum
- [ ] Teacher reviewed Form B for equivalent difficulty
- [ ] Form A administration date and room confirmed
- [ ] Form B administration date and room confirmed
- [ ] Assessment conditions and absence procedure documented
- [ ] Answer keys restricted from learners

## Product and safeguards

- [x] Automated classroom regression suite passed
- [x] Standard-form equivalent answers passed staging UAT
- [x] Lesson language switching preserved lesson step count in staging
- [x] Android learner flow reported working as expected by the product owner
- [ ] Representative low-bandwidth test completed
- [ ] Production release decision recorded
- [ ] Incident owner and escalation route confirmed

## Evidence collection

- [ ] Participant register created from `PILOT_DATA_DICTIONARY.md`
- [ ] Assessment table created
- [ ] Weekly engagement table created
- [ ] Feedback table created
- [ ] Incident log created
- [ ] Evidence folders and access permissions checked
- [ ] Weekly status owner confirmed
