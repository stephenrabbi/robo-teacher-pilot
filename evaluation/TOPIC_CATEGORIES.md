# Topic Categories for Pilot Analysis

Use one primary category per legitimate Mathematics question. If a question genuinely spans multiple topics, choose the category representing the main skill being assessed and note the ambiguity in analysis notes.

| Code | Topic | Examples |
|---|---|---|
| WHOLE_NUMBERS | Whole numbers and place value | Place value, ordering, operations with whole numbers |
| FACTORS_MULTIPLES | Factors, multiples and primes | Factors, multiples, prime/composite numbers |
| LCM_HCF | LCM and HCF | Lowest common multiple, highest common factor |
| FRACTIONS | Fractions | Equivalent fractions, operations with fractions |
| DECIMALS | Decimals | Decimal operations and fraction/decimal conversion |
| APPROXIMATION | Approximation and estimation | Rounding, estimating calculations |
| RATIO_PROPORTION | Ratio, proportion and rate | Ratios, unit rates, direct proportion |
| ALGEBRA | Algebraic expressions | Simplification, substitution, expressions |
| EQUATIONS | Simple linear equations | Solving one-step/simple equations |
| PROFIT_LOSS_PERCENTAGE | Everyday arithmetic | Profit, loss, discounts, percentages |
| MIXED_ARITHMETIC | Mixed arithmetic | Multi-step everyday arithmetic without one dominant topic |
| OUT_OF_SCOPE | Outside current scope | Non-JSS2/non-Mathematics questions |
| UNCLEAR | Cannot classify reliably | Insufficient context or ambiguous question |

## Important analysis rule

Topic frequency is a description of usage, not a direct measure of student weakness. A topic should only be described as a possible difficulty when the interaction evidence supports that interpretation (for example, repeated clarification requests or recurring errors), and the wording should remain cautious.
