# Robo-Teacher v2.6.1 — Privacy & Accessibility Patch

**Release date target:** 6 October 2026

This patch hardens the v2.6 Pilot Stable Release without adding learning features.

## Included

- Privacy Policy
- Terms of Use
- Terms & Conditions
- Cookie Policy
- Refund Policy
- business/operator details for Earlyon-Tech Brainery
- minor/parent-school permission wording at learner onboarding
- privacy/cookie choices with optional third-party content blocked by default
- privacy-conscious PhET iframe settings
- local-device data clearing control
- visible form labels and Clear actions for key inputs
- stronger keyboard focus treatment
- darker primary accent for improved WCAG contrast
- reduced and redacted interaction-log excerpts
- documented data inventory and third-party processor audit
- CI regression checks for these protections

## Analytics status

No advertising, behavioural analytics, Google Analytics or cross-site tracking script is added by this release.

## Scope

This patch does not alter Robo-Teacher's core tutoring, practice, diagnostic or mastery algorithms.


## Production acceptance and freeze

**Accepted production baseline:** Robo-Teacher v2.6.1  
**Acceptance confirmed:** 6 October 2026

The live production release passed end-to-end acceptance checks covering:
- learner onboarding and consent;
- typed, image and voice learning flows;
- Practice, Progress and return-session behaviour;
- privacy/legal links and privacy choices;
- optional third-party simulation consent;
- keyboard access and visible focus;
- teacher dashboard, learner codes and reports;
- privacy/data-minimisation controls;
- production deployment and live-page verification.

### Release freeze policy

Robo-Teacher v2.6.1 is now frozen as the accepted production baseline.

Changes to this release line are limited to:
1. critical production blockers;
2. security vulnerabilities;
3. privacy or data-protection defects;
4. data-loss or corruption risks;
5. failures in a core learner or teacher workflow.

New features, cosmetic enhancements and non-critical refinements move to the future backlog and must not reopen the accepted v2.6.1 release.

The next Robo-Teacher workstream is evidence, pilot results, product demonstration, school adoption and funding—not feature development.
