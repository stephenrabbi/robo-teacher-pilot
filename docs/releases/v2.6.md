# Robo-Teacher v2.6 — Pilot Stable Release

**Release date:** 6 October 2026

Robo-Teacher v2.6 is the stable pilot release following the V2.5 browser-classroom release and the subsequent classroom testing and stability work.

## Release baseline

The v2.6 release is based on the verified October 2026 main-branch build culminating in commit:

`7eafd76e4943537653701fe845d3400478bc6273`

GitHub Actions workflow **Robo-Teacher Tests**, run **#455**, completed successfully for that release point.

## Included since V2.5

- verified mobile-layout improvements;
- retained correction feedback and focused practice improvements;
- safer practice-answer handling;
- iPhone MP4 voice-recording compatibility;
- shared-device learner isolation;
- free-service wake-up handling that preserves learner questions;
- personalised recommended lessons connected to independent understanding checks;
- distinct evidence for mastery confirmation; and
- reset of completed answer controls when opening a new understanding check.

## Release policy

v2.6 is the feature-freeze point for the current pilot. New feature ideas should be placed in the future-version backlog. Changes to this release line should be limited to critical defects, security/privacy issues, or failures that block the core learner or teacher workflow.

## Historical note

V2.5 remains the major classroom feature milestone. v2.6 packages the subsequent pilot-driven stability and learning-flow improvements into a named stable release.
